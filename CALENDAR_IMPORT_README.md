# Calendar import

The companion `fabric_mastery_2026-11_to_2027-02.ics` contains all-day tasks with no invented clock times. Each item states the 120-minute Fabric and 45-minute SQL commitments. Target exam days are explicitly labelled as planning targets and not confirmed exam bookings.

Google Calendar web: Settings -> Import & export -> Select file -> choose your study calendar -> Import.

If you later connect Google Calendar, your actual busy/free hours can be considered before creating scheduled study blocks. Avoid importing the ICS twice because that may create duplicate entries.

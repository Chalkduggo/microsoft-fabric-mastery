# Interview preparation track

**Weekly cadence:** 2 x 10-minute oral explanations during review time; a longer mock interview on scheduled review days. Use your existing SQL revision for SQL problem solving.

## Technical question bank
1. Explain lakehouse vs warehouse tradeoffs.
2. Explain OneLake and shortcuts.
3. Design a star schema for subscriptions and viewing events.
4. Compare Import and Direct Lake semantic models.
5. Explain DAX row context vs filter context.
6. Compare pipeline, Dataflow Gen2, and notebook use cases.
7. Explain Delta transactions and medallion architecture.
8. Diagnose a slow PySpark join.
9. Explain Git branching and deployment lifecycle.
10. Describe controls for bad source data and pipeline failure.

## Internal and external storytelling
Create STAR-format examples from real contributions, identify business metrics, architecture decisions, your individual role, tradeoffs, and measurable outcomes. Do not exaggerate responsibility or claim production experience for a practice project.
